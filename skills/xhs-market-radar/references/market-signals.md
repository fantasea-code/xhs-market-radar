# 市场信号口径

本 skill 不强行输出“商业牵引高/中/低”。优先列原始信号和证据，让用户判断市场大小和商业化可能。

## 小红书主证据

记录原始信号：

- 爆款数量：同一方向是否有多条高互动笔记。
- 互动结构：赞、藏、评论比例；收藏高常表示教程/工具需求。
- 评论意图：求链接、求教程、求内测、问价格、吐槽、推荐替代方案。
- 内容供给：是否已有大量博主用同一卖法反复种草。
- 交易路径：店铺、私域、群、表单、邀请码、众筹、应用市场。
- 用户复用：是否有人反馈长期使用、迁移成本、续费、退订。

## 外部补证

外部数据不能替代小红书证据，只能补充商业判断。

| 来源 | 可记录字段 | 注意事项 |
|---|---|---|
| App Store | 排名、评分、评论数、更新时间、订阅价格 | 评论数不等于下载量 |
| 华为/小米/安卓市场 | 下载量区间、评分、评论、版本更新 | 不同市场口径不一致 |
| 淘宝/京东/抖音电商 | 价格、销量、评价、问答 | 注意刷量和 SKU 混合 |
| 官网/众筹页 | 定价、套餐、用户评价、发货状态 | 官网文案不能证明真实需求 |
| GitHub/Product Hunt | stars、issues、launch 评论 | 偏开发者市场，不代表大众市场 |
| 飞书/Notion 模板市场 | 复制量、收藏、价格、评论 | 更适合效率工具补证 |

外部补证硬规则：

- 下载量、销量、评分、价格、评论数等数字必须带来源链接或截图证据。
- 如果只听说或无法复查，写“待补”，不要写进总表当事实。
- 市场热度表的“对象”必须是产品/替代方案，不是单条小红书标题；小红书标题和链接单独放在“代表性小红书标题和链接”列。

## 写法要求

用原始信号写法：

```markdown
- 小红书互动：参考 1 有 1.2w 赞 / 8k 藏 / 530 评论；参考 2 有 240 评论，其中多条问“求链接/怎么买”。
- 外部补证：App Store 评论数 1.4k，近 30 天仍有更新；未拿到真实下载量。
- 交易线索：作者评论区引导私信/群，未看到公开店铺链接。
```

不要写成：

```markdown
- 商业牵引：高
```

## 伪需求判断

可以判断“疑似伪需求”，但必须写证据：

- 用户已有更低摩擦替代方案，并且评论区普遍选择替代方案。
- 笔记互动高但求购买/求教程/复用反馈很少。
- 竞品大量种草但评论集中吐槽价格、复杂度、效果不稳定。
- 外部下载/销量/评论长期低迷，且小红书也缺少真实使用反馈。

不要把以下情况误判为伪需求：

- 用户用通用工具或 DIY 流程硬凑场景时失败，例如用普通麦克风、录音笔、快捷指令、表格、Notion 模板自建复杂流程。这通常只能证明当前替代方案不适配，不能直接否定专用产品机会。
- 专用竞品被吐槽价格、续航、交互或输出质量，但评论区同时有人购买、追问、长期使用、期待迭代或明确认可核心输出。这说明需求和第一代产品能力要分开判断。
- 用户说“手机也能做”，但同时承认启动、整理、自动化、佩戴或场景切换有摩擦。此时应继续验证“专用入口是否足够降低摩擦”，不要直接判死。
